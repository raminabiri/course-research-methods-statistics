# دوره جامع مرور نظام‌مند، متاآنالیز، آمبرلا ریویو و بار بیماری‌ها

> از طرح سؤال پژوهش تا انتشار مقاله؛ با دو مسیر نرم‌افزاری مستقل: **CMA** و **R**

## این مخزن چیست؟

این مخزن محتوای کامل آموزشی یک دوره‌ی تخصصی است. همه‌ی محتوا به زبان فارسی نوشته شده و اصطلاحات تخصصی در اولین کاربرد، معادل انگلیسی‌شان را هم دارند. هر ماژول پنج جزء ثابت دارد:

| فایل | محتوا |
|---|---|
| `lesson.md` | درسنامه: اهداف یادگیری، متن درس، نکته‌ها و خطاهای رایج، جمع‌بندی |
| `references.md` | منابع متنی: فصل‌های کتاب، مقاله‌های مرجع (با DOI) و راهنماهای رسمی |
| `videos.md` | فیلم‌ها و وبینارهای آموزشی با لینک و وضعیت بررسی لینک |
| `exercises.md` | تمرین‌ها در سه سطح: مفهومی، کاربردی و پروژه‌ی پیوسته |
| `solutions.md` | حل تشریحی تمرین‌ها (در نسخه‌ی دانشجو حذف می‌شود) |
| `code/` | کدهای R همان ماژول (در صورت نیاز) |

## پرونده‌ی پیوسته (Running Case)

از فاز ۱ تا ۸، دانشجو روی **یک پرسش پژوهشی واحد** کار می‌کند تا هر مرحله خروجی مرحله‌ی قبل را ادامه دهد. این کار باعث می‌شود نتایج CMA و R با هم قابل مقایسه باشند. جزئیات: [data/README.md](data/README.md)
