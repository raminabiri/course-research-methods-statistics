# سرفصل کامل دوره

**نام دوره:** مرور نظام‌مند، متاآنالیز، آمبرلا ریویو و بار بیماری‌ها
**مخاطب:** دانشجویان تحصیلات تکمیلی و پژوهشگران علوم پزشکی و سلامت
**پیش‌نیاز:** آمار حیاتی و اپیدمیولوژی مقدماتی (با آزمون ورودی فاز ۰ سنجیده می‌شود)
**ساختار:** هسته‌ی اجباری (فاز ۱، فاز ۲ و یکی از فازهای ۳ یا ۴) و سه مسیر تخصصی (فازهای ۵، ۶ و ۷)

```
فاز ۰ ─► فاز ۱ ─► فاز ۲ ─┬─► فاز ۳ (CMA) ─┐
                          └─► فاز ۴ (R)   ─┴─► فاز ۵ / فاز ۶ / فاز ۷ (اختیاری) ─► فاز ۸
```

> **قرارداد شماره‌گذاری:** هر ماژول با حرف فاز و شماره نام‌گذاری می‌شود: `P1-M03` یعنی فاز ۱، ماژول ۳. در هر فاز، هر ماژول برابر یک جلسه‌ی ۳ ساعته است: ۹۰ دقیقه نظریه، ۶۰ دقیقه کار عملی و ۳۰ دقیقه بحث.
