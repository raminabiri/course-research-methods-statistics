# نظام ارزشیابی

## هسته‌ی اجباری (فاز ۱ + فاز ۲ + مسیر CMA یا R)

| جزء | سهم | توضیح |
|---|---|---|
| تمرین‌های هفتگی | ۲۰٪ | تمرین‌های سطح «کاربردی» هر ماژول |
| کارپوشه‌ی پرونده‌ی پیوسته | ۳۵٪ | خروجی‌های مرحله‌به‌مرحله‌ی پروژه‌ی شخصی (جدول پایین) |
| آزمون میان‌دوره (پایان فاز ۱) | ۱۵٪ | پرسش‌های چندگزینه‌ای مبتنی بر سناریو و نقد یک چکیده |
| آزمون عملی نرم‌افزار (پایان فاز ۳ یا ۴) | ۱۵٪ | اجرای متاآنالیز روی داده‌ی تازه در زمان محدود |
| مشارکت و داوری همتا | ۱۵٪ | داوری پروتکل و راهبرد جست‌وجوی یک هم‌کلاسی با چک‌لیست PRESS |

## خروجی‌های کارپوشه در فاز ۱

| هفته | خروجی | معیار پذیرش |
|---|---|---|
| ۱ | توجیه نوع مرور و جست‌وجوی مرورهای موجود | دست‌کم ۳ منبع بررسی‌شده (PROSPERO، Cochrane Library، PubMed با فیلتر مرور نظام‌مند) |
| ۲ | پرسش ساختارمند | همه‌ی اجزای چارچوب انتخاب‌شده تعریف عملیاتی دارند |
| ۳ | پیش‌نویس پروتکل | همه‌ی بندهای اجباری PRISMA-P پوشش داده شده‌اند |
| ۴ | راهبرد جست‌وجو | دست‌کم ۳ پایگاه، با واژه‌ی کنترل‌شده و واژه‌ی آزاد، و بدون خطای نحوی |
| ۵ | فایل غربالگری و نمودار PRISMA | دست‌کم ۱۰۰ رکورد با دو ارزیاب؛ ضریب کاپا گزارش شده است |
| ۶ | فرم استخراج آزموده‌شده | روی دست‌کم ۲ مطالعه آزموده و اصلاح شده است |
| ۷ | ارزیابی خطر سوگیری | ابزار متناسب با طرح مطالعه انتخاب شده؛ برای هر قضاوت دلیل نوشته شده است |
| ۸ | نقد یک مرور منتشرشده | چک‌لیست PRISMA 2020 و AMSTAR 2 هر دو تکمیل شده‌اند |

## مسیرهای تخصصی (فازهای ۵، ۶ و ۷)

هر مسیر گواهی جداگانه دارد. ارزشیابی هر مسیر ۴۰٪ تمرین و ۶۰٪ پروژه‌ی کوچک است: یک آمبرلا ریویوی محدود، یک تحلیل GBD با پرسش اصیل، یا یک تحلیل پیشرفته روی داده‌ی آماده.

## سیاست استفاده از هوش مصنوعی

- استفاده از ابزارهای هوش مصنوعی برای ویرایش زبانی، رفع خطای کد و ایده‌پردازی جست‌وجو **مجاز** است، به شرط آن‌که در پیوست تکلیف ذکر شود.
- واگذاری قضاوت‌های اصلی **مجاز نیست**: تصمیم نهایی غربالگری، استخراج عددی بدون وارسی انسانی، و قضاوت خطر سوگیری.
- هر عددی که در تکلیف آمده باید به صفحه یا جدول مشخصی از منبع اصلی قابل ردیابی باشد.
