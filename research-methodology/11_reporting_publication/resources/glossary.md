# واژه‌نامهٔ ماژول ۱۱

| واژه | برابر انگلیسی | توضیح کوتاه |
|---|---|---|
| رهنمود گزارش‌دهی | Reporting guideline | پیشنهادهای جامعهٔ علمی برای گزارش روشن و کامل یک طرح |
| چک‌لیست | Checklist | فهرست مواردی که باید در گزارش پیدا شوند |
| سند توضیحی | Explanation and elaboration | شرح چرایی و نمونهٔ هر مورد رهنمود |
| IMRaD | Introduction, Methods, Results, and Discussion | ساختار معمول برخی مقاله‌های پژوهش اصیل |
| اندازهٔ اثر | Effect estimate | مقدار برآوردشدهٔ تفاوت یا ارتباط |
| فاصلهٔ اطمینان | Confidence interval | بازه‌ای از مقادیر سازگار با داده و روش برآورد |
| مخرج | Denominator | شمار پایه‌ای که درصد یا نرخ بر آن تقسیم می‌شود |
| داوری همتا | Peer review | ارزیابی علمی مقاله پیش از یا پس از انتشار |
| نقش مشارکت‌کننده | Contributor role | نوع سهم فرد در تولید اثر علمی |
| پیش‌چاپ | Preprint | نسخه‌ای که پیش از داوری مجله به اشتراک گذاشته می‌شود |
| اصلاحیه | Correction | ثبت رسمی خطای مشخص در اثر منتشرشده |
| بیان نگرانی | Expression of concern | آگاهی‌رسانی سردبیر دربارهٔ نگرانی بررسی‌نشده |
| بازپس‌گیری مقاله | Retraction | هشدار رسمی دربارهٔ اتکاپذیری اثر منتشرشده |
| چکیدهٔ ساده‌زبان | Plain-language summary | شرح یافته برای خوانندهٔ غیرتخصصی |
| خطر مطلق | Absolute risk | شمار یا احتمال رخداد در جمعیت و زمان مشخص |
| خطر نسبی | Relative risk | نسبت خطر میان دو گروه |
| واحد درصد | Percentage point | تفاوت مستقیم دو درصد |
| ژورنال فریبنده | Deceptive journal | نشریه‌ای که فرایند یا ادعاهای نشر را گمراه‌کننده عرضه می‌کند |
| ژورنال ربوده‌شده | Hijacked journal | وبگاه جعلی که خود را نشریهٔ واقعی جا می‌زند |
| هزینهٔ پردازش مقاله | Article processing charge | هزینهٔ منتشرکردن یا دسترسی آزاد بر پایهٔ سیاست ناشر |
| نمایه | Index | سامانهٔ گزینش و ثبت رکوردهای علمی |
| چارک | Quartile | جایگاه نسبی مجله در دسته و سال مشخص |
| استناد | Citation | ارجاع ثبت‌شده به یک اثر در پایگاه معین |
| شاخص اچ | h-index | شاخصی که شمار مقاله و حداقل شمار استناد آن‌ها را ترکیب می‌کند |
| علم‌سنجی | Scientometrics | بررسی کمی تولید و ارتباطات علمی |
| ارزیابی مسئولانه | Responsible research assessment | داوری متناسب با هدف، بافت، محتوا و سنجه‌های محدود |
