# منابع ماژول ۱۱

منابع این ماژول شامل راهنماهای رسمی، مقاله‌های روش‌شناختی و ویدیوهای آموزشی است. برای سیاست ژورنال، نمایه و شاخص‌های جاری، صفحهٔ رسمی را دوباره بررسی کنید؛ ثبت پیوند به معنای بررسی همهٔ محتوای آن یا پخش فیلم نیست.
