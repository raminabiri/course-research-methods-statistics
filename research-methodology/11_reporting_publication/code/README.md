# نمونهٔ R برای گزارش نتیجه

فایل [`reporting.R`](reporting.R) با دادهٔ ساختگی همراه پروژه، جدول پایه، جملهٔ نتیجه و نمودار نقطه‌ای با دادهٔ خام و فاصلهٔ اطمینان می‌سازد. هیچ سطر آن دادهٔ بیمار یا پژوهش واقعی نیست.

## اجرا

از ریشهٔ `research-methodology` اجرا کنید:

```bash
Rscript --vanilla 11_reporting_publication/code/reporting.R
```

کد به `data/survey_data.csv` نیاز دارد. فایل داده با [`data/generate_data.R`](../../data/generate_data.R) از بذر ثابت تولید می‌شود. اجرای کد فایل‌های [`table1.csv`](table1.csv) و [`means_ci.png`](means_ci.png) را در همین پوشه می‌نویسد.

## خواندن خروجی با احتیاط

جدول، سن، جنس و چند ویژگی پایه را در دو گروه نشان می‌دهد. مدل نمونه، نمرهٔ پس‌آزمون را با گروه و نمرهٔ آغازین تحلیل می‌کند و ۱۲ ردیف فاقد نمرهٔ پس‌آزمون را کنار می‌گذارد. برای پژوهش واقعی باید شمار دادهٔ گمشده، دلیل نبود آن، طرح و هدف برآورد، خوشه‌بندی، مفروضه‌های مدل و تحلیل حساسیت را ارزیابی کرد.

این اسکریپت یک الگوی عمومی برای تحلیل همهٔ کارآزمایی‌ها نیست. پیش از بازاستفاده، با پروتکل و ساختار واقعی داده تطبیق دهید و خروجی را مستقل بازبینی کنید.
