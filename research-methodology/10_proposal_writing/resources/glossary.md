# واژه‌نامهٔ ماژول ۱۰

| واژه | برابر انگلیسی | توضیح |
|---|---|---|
| پروپوزال | Research proposal | سندی برای توجیه و برنامه‌ریزی پژوهش پیش از اجرا |
| پروتکل | Protocol | شرح نسخه‌دار پرسش، طرح، روش، حفاظت و تحلیل برنامه‌ریزی‌شده |
| بیان مسئله | Problem statement | استدلال دربارهٔ اهمیت، شواهد، شکاف و پرسش |
| شکاف دانشی | Knowledge gap | بخش مشخصی از پرسش که شواهد موجود پاسخ کافی به آن نداده‌اند |
| ارزش پژوهش | Research significance | دانشی یا تصمیمی که نتیجهٔ پژوهش می‌تواند پشتیبانی کند |
| نوآوری | Novelty | وجه تازه و مستند پژوهش در مفهوم، روش، جمعیت یا اجرا |
| هدف کلی | General aim | دستاورد اصلی که پژوهش در پی آن است |
| هدف اختصاصی | Specific objective | گام قابل ارزیابی برای رسیدن به هدف کلی |
| ماتریس همسویی | Alignment matrix | پیوند هدف، پرسش، متغیر، سنجه و تحلیل |
| واحد تخصیص | Unit of allocation | واحدی که گروه یا مداخله به آن اختصاص می‌یابد |
| بستهٔ کاری | Work package | فعالیتی با خروجی، مسئول و زمان روشن |
| نقطهٔ عطف | Milestone | نشانهٔ قابل سنجش از رسیدن به مرحله‌ای مهم |
| نمودار گانت | Gantt chart | نمایش زمانی فعالیت‌ها و هم‌پوشانی آن‌ها |
| زمان ذخیره | Contingency time | زمان کنارگذاشته‌شده برای تأخیرهای قابل پیش‌بینی |
| توجیه بودجه | Budget justification | پیوند مقدار و هزینهٔ هر قلم با فعالیت پژوهش |
| ماتریس خطر | Risk register | ثبت خطر، نشانه، پیامد، مسئول و پاسخ برنامه‌ریزی‌شده |
| نسخه‌بندی | Version control | ثبت نسخه، تاریخ و دلیل تغییر در پروتکل و پیوست‌ها |
| SPIRIT | Standard Protocol Items: Recommendations for Interventional Trials | رهنمود گزارش پروتکل کارآزمایی تصادفی |
| TIDieR | Template for Intervention Description and Replication | فهرست گزارش شرح مداخله برای فهم و بازتولید |
