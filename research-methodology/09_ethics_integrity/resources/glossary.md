# واژه‌نامهٔ ماژول ۹

| واژه | برابر انگلیسی | توضیح |
|---|---|---|
| اخلاق پژوهش | Research ethics | اصول و فرایندهای حفاظت از انسان، حیوان، جامعه و اعتبار دانش |
| رضایت آگاهانه | Informed consent | انتخاب داوطلبانه پس از دریافت و فهم اطلاعات مرتبط |
| موافقت کودک | Assent | بیان همراهی کودک متناسب با توان فهم او؛ جایگزین رضایت سرپرست در موارد لازم نیست |
| محرمانگی | Confidentiality | تعهد و تدبیر برای محدودکردن دسترسی یا افشای اطلاعات |
| دادهٔ ناشناس | Anonymous data | داده‌ای که به هویت فرد پیوندپذیر نیست |
| دادهٔ کدگذاری‌شده | Coded data | داده‌ای با شناسهٔ جایگزین که با کلید جداگانه دوباره پیوند می‌خورد |
| بازشناسی دوباره | Re-identification | پیوند داده با هویت فرد از راه شناسه یا ترکیب ویژگی‌ها |
| زیست‌بانک | Biobank | مجموعهٔ سازمان‌یافتهٔ نمونه‌های زیستی و داده‌های وابسته |
| جایگزینی | Replacement | جست‌وجوی روش معتبر به جای کار با حیوان، هرجا پاسخ علمی را فراهم کند |
| کاهش | Reduction | تعیین شمار حیوان به اندازهٔ لازم برای پاسخ علمی معتبر |
| بهسازی | Refinement | کاهش رنج و بهبود مراقبت و روش کار با حیوان |
| نقطهٔ پایان انسانی | Humane endpoint | معیار پیش‌توافق‌شده برای مداخله یا پایان مشارکت حیوان پیش از رنج شدید |
| جعل | Fabrication | ساختن داده یا نتیجه و گزارش آن به‌عنوان واقعیت |
| تحریف | Falsification | دست‌کاری داده، ماده یا فرایند به شکلی که سابقه واقعیت را بازنمایی نکند |
| سرقت ادبی | Plagiarism | برداشتن ایده، متن یا نتیجهٔ دیگری بدون ارجاع مناسب |
| تعارض منافع | Conflict of interest | منفعت ثانویه‌ای که می‌تواند بر قضاوت اثر بگذارد یا چنین برداشتی بسازد |
| سهم‌گذاری CRediT | Contributor Roles Taxonomy | واژگان استاندارد برای ثبت نقش‌های مشارکت در تولید پژوهش |
| پروتکل | Protocol | سند نسخه‌دار دربارهٔ پرسش، طرح، روش، حفاظت و تحلیل برنامه‌ریزی‌شده |
| ثبت پیش‌نگر | Prospective registration | ثبت عمومیِ طرح و پیامدها پیش از آغاز یا ورود شرکت‌کننده، طبق دامنهٔ الزام |
| انحراف از پروتکل | Protocol deviation | فاصلهٔ ثبت‌شده میان اجرای واقعی و نسخهٔ تأییدشده |
| بهبود کیفیت | Quality improvement | فعالیتی برای سنجش یا بهبود فرایند و خدمت؛ دسته‌بندی آن باید با نهاد محلی روشن شود |
| بازپس‌گیری مقاله | Retraction | اقدام نشر برای آگاه‌کردن خوانندگان از بی‌اعتباری یا مشکل جدی مقاله |
