# ماژول ۷: تعیین حجم نمونه و توجیه کفایت داده

این ماژول به شما کمک می‌کند پیش از دیدن داده، شمار لازم را برای پرسش پژوهشی خود تعریف و محاسبه کنید. محاسبهٔ حجم نمونه یک فرمول یکسان برای همهٔ مطالعه‌ها نیست: هدف برآورد، آزمون فرضیه، تحلیل بقا، دقت آزمون تشخیصی، ساخت مدل پیش‌بینی و پژوهش زیستی هرکدام ورودی‌ها و روش ویژهٔ خود را دارند.

## مسیر یادگیری

هر درس سه لایه دارد: مقدماتی برای فهم مفهوم، متوسط برای انتخاب و جای‌گذاری ورودی‌ها، و پیشرفته برای بررسی فرض‌ها و محدودیت‌ها. هر درس یک تمرین در هر سطح دارد؛ پاسخ گام‌به‌گام و معیار ارزیابی در پوشه‌ای جدا آمده است.
