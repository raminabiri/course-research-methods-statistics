# فصل ۷: تعیین حجم نمونه و توان آماری

## اهداف یادگیری
- فهم مؤلفه‌های حجم نمونه (α، β، اندازه اثر، واریانس)
- انتخاب فرمول/نرم‌افزار متناسب با طرح و هدف
- تعدیل برای ریزش، خوشه‌بندی و مقایسه‌های چندگانه و گزارش شفاف محاسبه

---

## ۱. چرا حجم نمونه؟
- **نمونه کوچک:** توان کم ← نتیجه منفی کاذب، برآورد بی‌دقت، **اغراق اندازه اثر در نتایج معنادار (Winner’s curse / خطای نوع M)**؛ و غیراخلاقی (درگیر کردن افراد بدون امکان پاسخ).
- **نمونه بیش از حد:** هدررفت منابع، اثرات بی‌اهمیت بالینی «معنادار» می‌شوند، و غیراخلاقی (مواجهه بیشتر با خطر).

## ۲. دو رویکرد
| رویکرد | هدف | ورودی |
|---|---|---|
| **دقت برآورد (Precision)** | مطالعات توصیفی: برآورد شیوع، میانگین | سطح اطمینان، **دقت/حاشیه خطا (d)**، واریانس یا p |
| **آزمون فرضیه (Power)** | مقایسه یا رابطه | α، توان (1−β)، اندازه اثر، واریانس، یک/دوطرفه، نسبت گروه‌ها |

## ۳. مؤلفه‌ها
|  | H0 درست است | H0 نادرست است |
|---|---|---|
| رد H0 | **خطای نوع اول (α)** — مثبت کاذب | **توان (1−β)** |
| عدم رد H0 | تصمیم درست (1−α) | **خطای نوع دوم (β)** — منفی کاذب |

- **α:** معمولاً ۰٫۰۵ دوطرفه (zα/2 = 1.96)؛ با مقایسه‌های چندگانه کوچک‌تر.
- **توان:** معمولاً ۰٫۸ (zβ = 0.84) یا ۰٫۹ (zβ = 1.28).
- **اندازه اثر (Effect size):** کوچک‌ترین اثری که **از نظر بالینی/عملی مهم** است (MCID)، نه اثری که «امیدواریم» ببینیم.
- **واریانس:** از مطالعات قبلی، پایلوت یا مرور؛ واریانس بیشتر ← نمونه بیشتر.
- **یک‌طرفه:** نمونه کمتر می‌خواهد ولی فقط با توجیه قوی و پیش‌ثبت‌شده.
- **نسبت تخصیص:** ۱:۱ کارآمدترین؛ بیش از ۱:۴ سود کمی دارد.

رابطه: n ∝ (zα + zβ)² × σ² / Δ² — **نصف کردن اندازه اثر، نمونه را ۴ برابر می‌کند.**

### اندازه‌های اثر استاندارد (کوهن ۱۹۸۸) — فقط وقتی اطلاعات بهتری ندارید
| شاخص | آزمون | کوچک | متوسط | بزرگ |
|---|---|---|---|---|
| d | t مستقل/زوجی | 0.2 | 0.5 | 0.8 |
| h | دو نسبت | 0.2 | 0.5 | 0.8 |
| r | همبستگی | 0.1 | 0.3 | 0.5 |
| f | ANOVA | 0.10 | 0.25 | 0.40 |
| f² | رگرسیون | 0.02 | 0.15 | 0.35 |
| w | کای‌اسکوئر | 0.1 | 0.3 | 0.5 |
| OR | – | ≈1.5 | ≈2.5 | ≈4.3 |

## ۴. فرمول‌های اصلی (α = 0.05 دوطرفه، توان ۰٫۸)
| هدف | فرمول |
|---|---|
| برآورد یک میانگین | n = z² σ² / d² |
| برآورد یک نسبت | n = z² p(1−p) / d² (p نامعلوم ← ۰٫۵ = بدترین حالت ← ۳۸۵ برای d = ۰٫۰۵) |
| اصلاح جامعه محدود | n = n₀ / [1 + (n₀ − 1)/N] |
| دو میانگین (هر گروه) | n = 2σ² (zα/2 + zβ)² / Δ² |
| دو نسبت (هر گروه) | n = [zα/2 √(2p̄q̄) + zβ √(p₁q₁ + p₂q₂)]² / (p₁ − p₂)² |
| زوجی | n = σd² (zα/2 + zβ)² / Δ² (σd = انحراف معیار تفاوت‌ها) |
| همبستگی | n = [(zα/2 + zβ) / (½ ln((1+r)/(1−r)))]² + 3 |
| بقا (شوئنفلد) | رویدادها = (zα/2 + zβ)² / [p(1−p)(ln HR)²]؛ N = رویدادها / احتمال رویداد |
| حساسیت (بودرر) | n_بیمار = z² Se(1−Se)/d²؛ N = n_بیمار / شیوع |
| عدم‌برتری (پیوسته) | n = 2σ² (zα + zβ)² / (M − δ)² (α یک‌طرفه ۰٫۰۲۵) |

### قواعد سرانگشتی (فقط برای کنترل منطق؛ جایگزین محاسبه نیستند)
- **رگرسیون خطی:** Green (1991): N ≥ 50 + 8m برای مدل کل؛ ۱۰–۲۰ نفر به ازای هر پیش‌بین.
- **رگرسیون لجستیک/کاکس:** **EPV ≥ 10** (Peduzzi 1996)؛ برای مدل‌های پیش‌بینی روش Riley و همکاران (2020) — بسته `pmsampsize`.
- **تحلیل عاملی:** ۵–۱۰ نفر به ازای هر گویه، حداقل ۲۰۰–۳۰۰؛ با اشتراک‌های بالا نمونه کمتر کافی است.
- **SEM:** حداقل ۲۰۰ یا ۱۰–۲۰ نفر به ازای هر پارامتر؛ بهتر: شبیه‌سازی مونت‌کارلو یا توان RMSEA.
- **مطالعه پایلوت:** ۱۲ نفر در هر گروه (Julious 2005) یا ۳۰ نفر؛ هدف پایلوت **امکان‌سنجی** است نه آزمون اثر.
- **مطالعات روان‌سنجی/پایایی:** ICC با ۳۰–۵۰ نفر؛ برای کاپا با فرمول‌های اختصاصی.
- **کیفی:** اشباع/قدرت اطلاعاتی (فصل ۶).

## ۵. تعدیل‌ها
- **ریزش:** n_نهایی = n / (1 − نرخ ریزش). (نه n × (1 + نرخ)!)
- **طرح خوشه‌ای:** × DEFF = 1 + (m − 1) ICC.
- **مقایسه‌های چندگانه:** α تعدیل‌شده (بونفرونی).
- **تعدیل برای کوواریت پایه (ANCOVA):** n × (1 − ρ²) که ρ همبستگی پیش‌آزمون و پس‌آزمون است ← کاهش نمونه.
- **زیرگروه‌ها:** اگر تحلیل زیرگروه هدف اصلی است، برای هر زیرگروه محاسبه کنید.
- **نسبت نامساوی:** n کل بیشتر برای همان توان.

## ۶. جدول کرجسی-مورگان و فرمول کوکران — هشدار
جدول **کرجسی و مورگان (۱۹۷۰)** فقط برای **برآورد یک نسبت** با p = 0.5، d = 0.05 و اطمینان ۹۵٪ است (همان فرمول کوکران با اصلاح جامعه محدود). استفاده از آن برای **مقایسه گروه‌ها، رگرسیون، کارآزمایی یا SEM نادرست است** — خطای بسیار رایج در پایان‌نامه‌های ایرانی.

## ۷. اشتباهات رایج
- **توان پس‌تجربی (Post-hoc/Observed power):** محاسبه توان با اندازه اثر مشاهده‌شده بی‌معناست (تابع مستقیم p-value است). به جای آن **فاصله اطمینان** گزارش کنید.
- اندازه اثر از **پایلوت کوچک** (بسیار ناپایدار)؛ به جای آن از حد بالای CI انحراف معیار پایلوت استفاده کنید.
- اندازه اثر «متوسط کوهن» بدون توجیه.
- فراموش کردن ریزش، خوشه‌بندی، یا نوع آزمون واقعی تحلیل (حجم نمونه باید با **آزمون اصلی تحلیل** همسو باشد).
- محاسبه برای هدف فرعی به جای پیامد اولیه.

## ۸. نرم‌افزارها
G*Power (رایگان، رایج‌ترین)، R (`pwr`، `pwrss`، `WebPower`، `presize`، `pmsampsize`، `simr` برای مدل‌های آمیخته)، OpenEpi (آنلاین)، PASS و nQuery (تجاری، کامل‌ترین)، SPSS (≥ ۲۷: Power Analysis)، Stata (`power`)، **شبیه‌سازی** برای طرح‌های پیچیده.

## ۹. الگوی گزارش در پروپوزال/مقاله (CONSORT/SPIRIT)
