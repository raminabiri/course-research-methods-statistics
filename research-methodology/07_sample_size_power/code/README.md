# کدهای محاسبهٔ حجم نمونه

- [نمونه‌های R](sample_size.R) شامل برآورد میانگین و نسبت، مقایسهٔ گروه‌ها، همبستگی، رگرسیون، بقا، دقت تشخیصی، تعدیل خوشه و ریزش و رسم منحنی توان است.
- [نمونهٔ SPSS](sample_size.sps) نگه داشته شده است، اما در این مرحله اجرا و راستی‌آزمایی نشده است.
- [بازگشت به ماژول ۷](../README.md)

## اجرا

از پوشهٔ `research-methodology` اجرا کنید:

```text
Rscript 07_sample_size_power/code/sample_size.R
```

کد R برای نمونه‌های آموزشی نوشته شده است. پس از اجرای آن، خروجی منحنی توان در `07_sample_size_power/code/power_curve.png` ذخیره می‌شود. برخی محاسبه‌ها تقریب نرمال‌اند؛ برای طرح نهایی، آزمون، مفروضه‌ها، روش تحلیل و نرم‌افزار را با پژوهشگر آمار بازبینی کنید.

در برآورد دقت تشخیصی، شمار مبتلایان ابتدا رو به بالا گرد می‌شود و سپس با شیوع به شمار کل تبدیل می‌شود. آزمون‌های درون کد انتظار دارند حساسیت ۹۰٪، دقت ۰٫۰۵ و شیوع ۲۰٪ دست‌کم ۱۳۹ مبتلا و ۶۹۵ نفر در کل بدهد.
