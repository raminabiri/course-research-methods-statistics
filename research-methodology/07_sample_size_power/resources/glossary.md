# واژه‌نامهٔ ماژول ۷

| واژه | برابر انگلیسی | توضیح |
|---|---|---|
| حجم نمونه | Sample size | شمار واحدهای مستقل لازم یا موردنیاز برای تحلیل؛ باید روشن شود منظور شمار جذب‌شده، شمار پاسخ‌کامل یا شمار رویداد است. |
| توان آماری | Statistical power | احتمال رد فرض صفر در صورت درست‌بودن اثر مشخصی که برای محاسبه فرض شده است. |
| خطای نوع اول | Type I error | احتمال رد فرض صفر در حالی که فرض صفر درست است؛ اغلب با `α` نشان داده می‌شود. |
| خطای نوع دوم | Type II error | احتمال ردنکردن فرض صفر در صورت وجود اثر مشخص؛ اغلب با `β` نشان داده می‌شود. |
| تفاوت مهم | Meaningful difference | کمترین تفاوتی که از نظر بالینی، زیستی یا تصمیم‌گیری ارزش شناسایی دارد. |
| اندازهٔ اثر | Effect size | اندازهٔ کمی تفاوت یا رابطه‌ای که محاسبه بر پایهٔ آن انجام می‌شود. |
| حاشیهٔ خطا | Margin of error | نصف پهنای فاصلهٔ اطمینان در برآورد یک کمیت. |
| انحراف معیار | Standard deviation | شاخص پراکندگی مقدارها پیرامون میانگین؛ در محاسبه باید از جمعیت و ابزار مشابه بیاید. |
| نسبت تخصیص | Allocation ratio | نسبت شمار افراد میان گروه‌ها، مانند ۱:۱ یا ۲:۱. |
| رویداد | Event | رخداد مورد تحلیل در پژوهش زمان‌تا‌رویداد؛ شمار آن با شمار کل شرکت‌کنندگان یکی نیست. |
| سانسور | Censoring | حالتی که زمان دقیق رویداد برای فرد معلوم نیست، چون پیگیری پیش از وقوع یا ثبت رویداد پایان یافته است. |
| نسبت مخاطره | Hazard ratio | نسبت نرخ‌های لحظه‌ای وقوع رویداد میان دو گروه در طول زمان، با فرض‌های مدل مربوط. |
| حساسیت | Sensitivity | سهم افراد دارای بیماری که آزمون آن‌ها را مثبت شناسایی می‌کند. |
| ویژگی | Specificity | سهم افراد بدون بیماری که آزمون آن‌ها را منفی شناسایی می‌کند. |
| شیوع | Prevalence | سهم افراد دارای وضعیت موردنظر در جمعیت تعریف‌شده. |
| اثر طرح | Design effect | نسبت واریانس برآورد در طرح واقعی به واریانس همان برآورد در نمونه‌گیری سادهٔ هم‌اندازه. |
| همبستگی درون‌خوشه‌ای | Intracluster correlation coefficient | میزان شباهت اعضای یک خوشه در پیامد؛ بر دقت و حجم نمونه اثر می‌گذارد. |
| تکرار زیستی | Biological replicate | واحد زیستی مستقل که پاسخ پژوهش دربارهٔ آن تعمیم داده می‌شود. |
| تکرار فنی | Technical replicate | چند سنجش از یک واحد زیستی؛ این سنجش‌ها جای چند واحد مستقل را نمی‌گیرند. |
| واحد آزمایشی | Experimental unit | کوچک‌ترین واحدی که مداخله به‌طور مستقل به آن تخصیص می‌یابد. |
| ریزش | Attrition | از دست‌رفتن شرکت‌کنندگان یا داده‌های قابل‌تحلیل در جریان پژوهش. |
| بی‌پاسخی | Nonresponse | پاسخ‌ندادن واحد نمونه‌گیری یا ندادن پاسخ به بخشی از ابزار گردآوری داده. |
| توسعهٔ مدل | Model development | ساخت مدل پیش‌بینی از داده‌های پژوهشی، شامل برآورد ضرایب و انتخاب روش مناسب. |
| اعتبارسنجی بیرونی | External validation | سنجش کارایی مدل ازپیش‌ساخته‌شده در داده یا جمعیتی مستقل از دادهٔ توسعه. |
| کالیبراسیون | Calibration | میزان توافق میان خطر پیش‌بینی‌شده و فراوانی رخداد ثبت‌شده. |
| بیش‌برازش | Overfitting | یادگیری الگوهای ویژهٔ دادهٔ توسعه به‌جای رابطهٔ پایدار؛ کارایی مدل در دادهٔ تازه افت می‌کند. |
| پارامتر | Parameter | کمیت مستقلی که باید از داده برآورد شود؛ ضرورتی ندارد شمار پارامترها با شمار متغیرهای نامزد برابر باشد. |
| پایلوت | Pilot study | مطالعهٔ مقدماتی برای بررسی امکان اجرای فرایند یا آماده‌کردن پژوهش بزرگ‌تر؛ به‌خودی‌خود آزمون قطعی اثربخشی نیست. |
| توان پس از پژوهش | Post hoc power | محاسبه‌ای پس از گردآوری داده که اغلب از اندازهٔ اثر برآوردشده و مقدار `p` بازنویسی می‌شود و جای فاصلهٔ اطمینان را نمی‌گیرد. |
