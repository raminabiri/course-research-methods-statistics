# کد آموزشی نمونه‌گیری

کد R مکمل درس است؛ خواندن درس و حل ۷۲ تمرین به نصب R وابسته نیست. دادهٔ همراه پروژه ساختگی است. هیچ بسته‌ای در زمان اجرا نصب نمی‌شود و اجرای کد اینترنت نمی‌خواهد.

از ریشهٔ پروژه:

```bash
Rscript --vanilla 06_sampling/code/sampling.R
Rscript --vanilla 06_sampling/code/check_sampling.R
```

اسکریپت مسیر داده را از جای فایل خود پیدا می‌کند و از پوشهٔ دیگری نیز قابل اجراست. گزینهٔ `--vanilla` تنظیمات شخصی R را وارد اجرای آموزشی نمی‌کند.

## پوشش

- انتخاب ساده بدون جایگذاری و منظم با فاصلهٔ حقیقی.
- تخصیص متناسب و نیمن با گردکردن جمع‌پذیر و قاعدهٔ روشن تساوی.
- انتخاب خوشه و دو مرحله در دادهٔ ساختگی هم‌اندازه.
- یک برداشت با احتمال متناسب با اندازه؛ این تابع، انتخاب چند خوشه و احتمال ورود نهایی آن‌ها را محاسبه نمی‌کند.
- شبیه‌سازی مقایسهٔ پراکندگی برآوردها برای همان جامعهٔ آموزشی.
- توالی بلوکی آموزشی با ثبت کامل‌بودن بلوک پایانی؛ توازن نهایی پس از برش تضمین نمی‌شود.

## حدود

تابع تخصیص برای طرح دارای حداقل اجباری، طبقهٔ با سهم صفر یا سقف پرشده، خطا می‌دهد تا بازطراحی انجام شود. حل بهینه‌سازی پیچیده در این کد نیست. تساوی باقی‌مانده‌ها با ترتیب ورود طبقه‌ها شکسته می‌شود. کد توالی بلوکی کنترل دسترسی و سامانهٔ پنهان‌سازی بالینی ندارد و سامانهٔ اجرایی کارآزمایی نیست.

فایل `sampling.sps` پیش‌نویس پیشین است و در این محیط اجرا نشده؛ برای آن برچسب اعتبارسنجی درج نشده است. پاسخ هیچ تمرین تازه به اجرای SPSS وابسته نیست.


اعداد وابسته به نسخهٔ R و مولد تصادفی‌اند؛ نزدیک‌تربودن یک برآورد در یک اجرا، رتبه‌بندی دقت روش‌ها نیست. خروجی کامل و نسخهٔ محیط در [گزارش بررسی](../../reports/sampling_review.md) آمده است.
