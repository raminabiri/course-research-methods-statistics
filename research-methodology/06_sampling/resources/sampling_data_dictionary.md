# فرهنگ دادهٔ مسیر نمونه‌گیری

این جدول الگوی طراحی است؛ هر پژوهش تنها داده‌های لازم خود را با تعریف روشن گردآوری کند. نمونه‌های آموزشی باید ساختگی و بدون دادهٔ هویتی باشند.

| نام فیلد | معنا | کنترل پیشنهادی |
|---|---|---|
| study_id | شناسهٔ فرد یا منبع زیستی | یکتا در جدول منابع اصلی |
| frame_version | نسخهٔ فهرست مبنای انتخاب | تاریخ و شناسهٔ نسخه موجود باشد |
| stratum_id | شناسهٔ طبقه | تهی‌بودن یا تعریف طبقه ثبت شود |
| psu_id | خوشهٔ مرحلهٔ نخست | درون طرح و طبقه قابل شناسایی باشد |
| household_id | شناسهٔ خانوار | با فرد یکی گرفته نشود |
| p_stage1 | احتمال ورود در گام نخست | بزرگ‌تر از صفر و تا یک |
| p_stage2_cond | احتمال شرطی گام دوم | بزرگ‌تر از صفر و تا یک |
| p_person_cond | احتمال انتخاب فرد در خانوار | متناسب با روش انتخاب فرد |
| inclusion_probability | احتمال نهایی مسیر | حاصل‌ضرب عامل‌ها در طرح سادهٔ چندمرحله‌ای |
| base_weight | وزن پایه | معکوس احتمال نهایی |
| response_adjustment | ضریب تعدیل بی‌پاسخی | منبع و فرض گروه تعدیل ثبت شود |
| calibration_factor | عامل کالیبراسیون | منبع مجموع‌های جمعیتی ثبت شود |
| final_weight | وزن نهایی | روش ساخت و دامنهٔ کاربرد روشن باشد |
| eligibility_status | واجد شرایط، بیرون از معیار یا نامعلوم | کدهای جدا؛ نامعلوم صفر فرض نشود |
| contact_attempts | شمار تلاش تماس | عدد صحیح نامنفی |
| final_disposition | سرنوشت نهایی | مشارکت، انصراف، غیبت و دیگر علت‌ها جدا |
| biological_source_id | شناسهٔ منبع زیستی | پیوند نمونه‌های وابسته نگه داشته شود |
| experimental_unit_id | شناسهٔ واحد دریافت مداخله | سطح آن در پروتکل تعریف شود |
| technical_replicate_id | شناسهٔ تکرار فنی | درون منبع و نوبت سنجش تعریف شود |
| batch_id | دسته، صفحه یا روز سنجش | گروه درمانی با دسته یکی نشده باشد |
| deviation_id | شناسهٔ انحراف از روش کار | علت، تاریخ و تصمیم در دفتر جدا |

## دو جدول به‌جای تکرار هویت

جدول منبع اصلی یک ردیف برای هر فرد یا منبع زیستی دارد. جدول سنجش‌ها چند ردیف با شناسهٔ پیوندی دارد. بدین ترتیب شمار خوانش با شمار منبع زیستی یکی نمی‌شود. راه تماس و نام افراد در جدول محدود و جدا نگه داشته شوند.

این فرهنگ به فایل ساختگی `data/survey_data.csv` افزوده نشده است؛ آن فایل برای نمایش سادهٔ روش‌هاست و همهٔ گام‌های کار میدانی را ندارد.
