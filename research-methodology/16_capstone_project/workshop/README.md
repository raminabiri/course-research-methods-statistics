# کارگاه بستهٔ نهایی

همهٔ سطرهای `followup.csv` ساختگی‌اند. ستون `case_id` شناسهٔ آموزشی، `due` سررسید شدن و `completed` ثبت پیگیری را نشان می‌دهد. ۱ یعنی بله، ۰ یعنی خیر و خانهٔ خالی در ستون پیگیری یعنی هنوز سررسید نشده است.

برای بازتولید عدد، پوشهٔ کارگاه را باز کنید و با Python 3 در همان پوشه فرمان زیر را اجرا کنید. کتابخانهٔ افزوده نیاز نیست.

```sh
python3 summarize.py
```

انتظار: ۱۲ پرونده، ۱۰ مورد سررسیدشده، ۹ مورد پیگیری کامل و نرخ ۹۰٫۰٪. سپس یک سطر پیگیری کامل را در نسخه‌ای جدا به ۰ تغییر دهید. نرخ باید ۸۰٫۰٪ شود. پیش از تحویل نسخهٔ اصلی را برگردانید و بار دیگر اجرا کنید.
