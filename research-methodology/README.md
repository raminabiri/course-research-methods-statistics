> سطح: مقدمات پیشرفته — برای دانشجویان ارشد/دکتری و پژوهشگران تازه‌کار
> زبان: فارسی (اصطلاحات کلیدی همراه معادل انگلیسی)
> نرم‌افزار: R (≥ 4.2) و IBM SPSS (≥ 26؛ دستورات POWER از نسخه ۲۷)

## ۱. نظر طراح درباره سرفصل‌های پیشنهادی

سرفصل‌های پیشنهادی (انواع مطالعات، نمونه‌گیری، حجم نمونه، گزارش‌دهی، پروپوزال، گرنت بین‌المللی، مدیریت پروژه و پژوهش، روان‌شناسی و جامعه‌شناسی پژوهشگر) **زیاد نیستند**؛ به شرطی که هر فصل فشرده و مفهوم‌محور باشد و آموزش آمار به «برنامه تحلیل» محدود شود (این درس، درس آمار نیست).

اما چند **حلقه گمشده** دارد که بدون آن‌ها زنجیره پژوهش کامل نمی‌شود؛ این‌ها افزوده شد:

| افزوده | چرا لازم است |
|---|---|
| مبانی، پارادایم‌ها و پرسش پژوهش (فصل ۱) | همه طراحی‌ها از پرسش درست شروع می‌شوند (FINER/PICO) |
| مرور متون، مرور نظام‌مند و متاآنالیز (فصل ۲) | پیش‌نیاز بیان مسئله و پروپوزال؛ خودش یک نوع مطالعه است |
| سوگیری، مخدوش‌گری و علیت (فصل ۴) | بدون آن، «انواع مطالعات» تنها فهرست اسم است |
| اندازه‌گیری، پرسشنامه، روایی و پایایی (فصل ۵) | رایج‌ترین نقطه ضعف پایان‌نامه‌ها در ایران |
| مدیریت داده و برنامه تحلیل (فصل ۸) | پل بین طراحی و گزارش؛ جلوگیری از p-hacking |
| اخلاق و صداقت پژوهشی (فصل ۹) | الزام قانونی (کد اخلاق، ثبت کارآزمایی) و پایه اعتماد |
| علم باز، تکرارپذیری، ابزارها و هوش مصنوعی (فصل ۱۵) | موضوع روز و الزام بسیاری از فاندرها و مجلات |
| پروژه پایانی (فصل ۱۶) | یکپارچه‌کردن همه فصل‌ها در یک پروپوزال واقعی |

**ترتیب منطقی:** فصل‌ها به ترتیب «چرخه عمر یک پژوهش» چیده شده‌اند: ایده → مرور → طراحی → کنترل خطا → اندازه‌گیری → نمونه → حجم نمونه → داده و تحلیل → اخلاق → پروپوزال → گزارش و انتشار → تأمین مالی → مدیریت → انسانِ پژوهشگر → علم باز.

**تأکید ویژه:** طبق خواسته، فصل ۱۳ (مدیریت پروژه و مدیریت پژوهش) مفصل‌ترین فصل است و هر دو سطح «مدیریت یک پروژه» و «مدیریت پژوهش در سطح سازمان» را پوشش می‌دهد.

**یک هشدار درباره گرنت‌ها:** شرایط واجد شرایط بودن (eligibility) فراخوان‌های خارجی برای پژوهشگران ایرانی مرتباً تغییر می‌کند (تحریم، انتقال پول، کشورهای مشمول). در فصل ۱۲ سازوکارها آموزش داده شده، ولی هر فراخوان باید در زمان اقدام از سایت رسمی بررسی شود.

ساختار هر پوشه‌ی فصل (الگوی فصل ۱؛ فصل‌های دیگر هنوز پیش‌نویس قدیمی‌اند و به این الگو درمی‌آیند):

| فایل | محتوا |
|---|---|
| `README.md` | اهداف، پیش‌نیاز، زمان، ترتیب مطالعه، وضعیت |
| `01_lesson_<topic>.md`، `02_lesson_<topic>.md`، … | درس‌ها (هر کدام ۳۰ تا ۶۰ دقیقه): داستان، مفهوم به زبان ساده، «✋ امتحان کن»، سه اشتباه رایج، واژه‌نامه، منابع |
| `NN_exercises.md` | تمرین‌ها، با راهنمایی زیر هر تمرین |
| `NN_solutions.md` | پاسخ تشریحی |
| `code/*.R`، `code/*.sps` | کد R و SPSS (فصل‌هایی که کد دارند) |

نام پوشه‌ها و فایل‌ها لاتین است تا در R، SPSS و Git مشکل مسیر پیش نیاید؛ محتوا فارسی است.

## ۴. راه‌اندازی نرم‌افزار

```bash
# از ریشه پروژه (برای ساخت دوباره داده‌ها)
Rscript data/generate_data.R
```

```r
# بسته‌های اختیاری R (کدها بدون آن‌ها هم با R پایه کار می‌کنند)
install.packages(c("pwr", "psych", "irr", "metafor", "dagitty", "survey", "ggplot2"))
```

در SPSS: ابتدا در هر فایل `.sps` مسیر `FILE=` را به مسیر پوشه `data` روی سیستم خود تغییر دهید.
