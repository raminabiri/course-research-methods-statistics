# اجرای نمونه‌های کد ماژول ۸

## داده و زبان اجرا

فایل CSV همراه پوشهٔ `data/` ساختگی و بدون اطلاعات واقعی است. کد R با پایهٔ خود R اجرا می‌شود و بستهٔ افزوده نمی‌خواهد. مسیر داده بر پایهٔ محل فایل کد ساخته می‌شود؛ می‌توانید آن را از هر پوشه اجرا کنید:

```bash
Rscript --vanilla research-methodology/08_data_management_analysis/code/analysis.R
```

کد تعداد ردیف، الگوی نبود پیامد، کنترل‌های دامنه، آزمون مقایسهٔ خام و مدل تعدیل‌شده را چاپ می‌کند. مدل کامل‌موردی فقط برای نمایش خروجی است؛ انتخاب آن برای پژوهش واقعی نیاز به توجیه فرض‌ها دارد. تحلیل این داده، سازوکار گم‌شدن را از روی خروجی اثبات نمی‌کند.

برای بازسازی CSV ساختگی، اجرا کنید:

```bash
Rscript --vanilla research-methodology/08_data_management_analysis/code/generate_synthetic_data.R
```

## SPSS

فایل `analysis.sps` همان CSV را وارد می‌کند، متغیرهای اصلی را توصیف می‌کند و نمونه‌ای از آزمون و مدل تعدیل‌شده نشان می‌دهد. دستور `GET DATA` مسیر را نسبت به ریشهٔ `research-methodology` فرض می‌کند. مسیر را در صورت اجرای فایل از پوشه‌ای دیگر تغییر دهید.

SPSS در این محیط نصب یا اجرا نشده است؛ سازگاری نسخه و اجرای دستورها نیازمند آزمون کاربر است. خروجی عددی SPSS در پاسخ تمرین‌ها ادعا نشده است.

## حدود کد

کد برای یادگیری مسیر بازبینی و خواندن خروجی است، نه توصیهٔ تحلیل برای یک پروتکل واقعی. دادهٔ ساختگی پاسخ گم‌شده دارد، اما اسکریپت جایگذاری چندگانه یا تحلیل کامل حساسیت را اجرا نمی‌کند. برای پژوهش واقعی، مدل و جمعیت تحلیل را در برنامهٔ تحلیل ازپیش مشخص کنید و در صورت نیاز از مشورت آماری بهره بگیرید.
