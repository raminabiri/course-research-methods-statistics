# واژه‌نامهٔ ماژول ۸

| واژه | برابر انگلیسی | توضیح کوتاه |
|---|---|---|
| فرهنگ داده | Data dictionary | تعریف، نوع، واحد، دامنه و کدهای هر متغیر |
| فراداده | Metadata | داده دربارهٔ منشأ، ساختار، پردازش و زمینهٔ داده |
| شناسهٔ پژوهشی | Study identifier | کد غیرمستقیم برای پیوند رکوردها |
| ردپای ممیزی | Audit trail | ثبت تغییر، دلیل، زمان و مسئول |
| دادهٔ گمشده | Missing data | مقدار مشاهده‌نشده برای متغیر تعریف‌شده |
| MCAR | Missing completely at random | گم‌شدن مستقل از مقادیر مشاهده‌شده و مشاهده‌نشده |
| MAR | Missing at random | گم‌شدن مستقل از مقدار مشاهده‌نشده پس از شرط‌گذاری بر متغیرهای مشاهده‌شده |
| MNAR | Missing not at random | وابستگی گم‌شدن به مقدار مشاهده‌نشده حتی پس از شرط‌گذاری |
| جایگذاری چندگانه | Multiple imputation | ساخت چند مجموعهٔ کامل و ترکیب برآوردها با حفظ عدم‌قطعیت |
| برنامهٔ تحلیل آماری | Statistical analysis plan | سند تصمیم‌های تحلیل، پیش از تفسیر نتیجه |
| برآورد هدف | Estimand | کمیت علمی مورد نظر در پرسش اثر |
| تحلیل اکتشافی | Exploratory analysis | تحلیلی برای ساخت یا بررسی فرضیه، نه آزمون تأییدی ازپیش‌مشخص‌شده |
| مقدار p | P-value | احتمال داده‌ای دست‌کم به این اندازه ناسازگار با فرض صفر، مشروط بر فرض‌ها و مدل |
| نام‌مستعارسازی | Pseudonymization | جایگزینی شناسهٔ مستقیم با کد، با امکان پیوند از راه کلید جداگانه |
| تکرار زیستی | Biological replicate | واحد مستقل زیستی که دامنهٔ استنباط به آن وابسته است |
| تکرار فنی | Technical replicate | تکرار سنجش یک نمونه برای ارزیابی خطای اندازه‌گیری |
| اثر دسته | Batch effect | تغییر ناشی از نوبت، دستگاه، اپراتور یا دستهٔ پردازش |
| بازاندیشی پژوهشگر | Researcher reflexivity | بررسی نقش و پیش‌فرض پژوهشگر در تولید و تفسیر داده |
